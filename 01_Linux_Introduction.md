# Linux Introduction

## Description

Linux is a free and open-source operating system based on Unix. It is widely used in servers, cloud computing, cybersecurity, networking, embedded systems, and software development.

Linux is known for its stability, security, flexibility, and powerful command-line interface.

Many cybersecurity tools and platforms, including Kali Linux, are built on Linux.

---

# What is an Operating System?

An Operating System (OS) is system software that acts as an interface between users and computer hardware.

Functions of an Operating System:

* Manage hardware resources
* Manage files and directories
* Manage memory
* Manage processes
* Provide security
* Run applications

Examples:

* Linux
* Windows
* macOS

---

# What is Linux?

Linux is an open-source operating system kernel created by Linus Torvalds in 1991.

The Linux kernel is the core component of the operating system and manages communication between hardware and software.

# Linux Architecture

Linux architecture consists of:

```text
User
  ↓
Applications
  ↓
Shell
  ↓
Kernel
  ↓
Hardware
```

---

# Kernel

The Kernel is the core component of Linux.

Functions:

* Process Management
* Memory Management
* Device Management
* File System Management

The kernel acts as a bridge between software and hardware.

---

# Shell

The Shell is a command interpreter that allows users to interact with the operating system.

Common Linux shells:

* Bash
* Zsh
* Fish
* Sh

Example command:

```bash
pwd
```

This command displays the current working directory.

---

# Linux Distributions

A Linux Distribution (Distro) is a complete operating system built around the Linux kernel.

Popular distributions:

* Ubuntu
* Debian
* Kali Linux
* Fedora
* Arch Linux
* CentOS

---

# Kali Linux

Kali Linux is a Debian-based Linux distribution designed for cybersecurity professionals and ethical hackers.

Features:

* Security tools included
* Penetration testing environment
* Digital forensics support
* Wireless security tools

---

# Linux File System

Linux organizes data using a hierarchical file system.

Example:

```text
/
├── home
├── etc
├── var
├── usr
├── bin
└── tmp
```

The root directory is represented by:

```text
/
```

# Linux Users

Linux supports multiple users.

Common user types:

* Root User

# Root User

The root user has complete control over the system.

Example:

```bash
sudo su
```

Root privileges should be used carefully.
